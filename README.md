# 📌 Overview

**StayEase** is a full-stack web application that allows users to discover, explore, create, and book unique stays across different locations.  
The platform provides an intuitive user experience with interactive maps, authentication, image uploads, reviews, and property management.

Built with a scalable MVC architecture and modern web technologies, StayEase delivers a smooth booking experience similar to leading accommodation platforms.

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Sumit93500/StayEase.git
```

## 2️⃣ Navigate to Project Folder

```bash
cd StayEase
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Setup Environment Variables

Create a `.env` file and add:

```env
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_KEY=your_key
CLOUDINARY_SECRET=your_secret

MAP_TOKEN=your_map_token

DB_URL=your_mongodb_url

SECRET=session_secret
```

## 5️⃣ Start the Server

```bash
npm start
```
